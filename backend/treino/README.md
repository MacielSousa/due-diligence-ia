# Treino do desafio

`esqueleto/` tem as classes do domínio **vazias** (com `TODO`), do jeito que estavam antes de
serem implementadas. É material de treino, não é código usado pela aplicação.

Para praticar:

```bash
cd backend
cp treino/esqueleto/*.php app/Domain/DueDiligence/   # o Documento.php não é sobrescrito
composer test:desafio                                 # rode até os 7 testes passarem
```

Para voltar à solução oficial: `git checkout -- app/Domain/DueDiligence`.
